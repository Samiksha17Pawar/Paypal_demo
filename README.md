# PayPal Landing Page – React

**Created by Samiksha Pawar | MCA Full Stack Development Assignment**

## About the Project

This is a PayPal-inspired landing page built using React.js, JavaScript, and CSS. The project was created to practise frontend development, component-based architecture, and modern web page styling.

## Features

- PayPal-inspired navigation bar and landing page.
- Personal and Business toggle section.
- Hero section with heading, description, and call-to-action buttons.
- Reusable React components.
- Custom CSS styling.
- Link to the official PayPal India website through the Personal navigation item.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Git and GitHub

## How to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/Samiksha17Pawar/Paypal_demo.git
```

**2. Navigate to the project folder**

```bash
cd Paypal_demo
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.
